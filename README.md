# Nazdar careers pages

Seven self-contained pages. Each file includes its own fonts, styles and scripts, so they work opened directly from disk or served from GitHub Pages.

- index.html (Careers overview)
- culture.html
- community.html
- benefits.html
- history.html
- leadership.html
- faq.html

Upload all seven files to the root of the repository. To publish: Settings > Pages > Deploy from a branch > main, / (root).

Leadership photos, community logos and wellness badges load from nazdar.com and need an internet connection.
